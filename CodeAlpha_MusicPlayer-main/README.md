# CodeAlpha Music Player

## Project Description

This project is a responsive Music Player developed as part of the CodeAlpha Frontend Development Internship. It is built using HTML, CSS, and JavaScript. The application allows users to play, pause, and navigate through songs with an interactive and user-friendly interface.

## Features

- Play and pause music
- Next and Previous track navigation
- Display song title and artist
- Display song duration
- Progress bar
- Volume control
- Responsive design
- Playlist and autoplay support

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
CodeAlpha_MusicPlayer/
├── index.html
├── styles.css
└── script.js
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Use the player controls to play, pause, and navigate through the songs.
